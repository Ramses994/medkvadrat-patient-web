# medkvadrat-patient-web

Личный кабинет пациента сети клиник МедКвадрат — веб-приложение **только на чтение**.

Пациент входит по телефону и коду с e-mail, смотрит предстоящие записи, историю посещений и профиль. Запись, отмена и перенос приёма в этот репозиторий не входят.

**Статус:** пилот внутри сети клиники.

![Снимок экрана на вымышленных данных](docs/screenshot-fictional.svg)

## Стек

- Vite + React + TypeScript (статическая сборка)
- nginx (непривилегированный): статика + прокси `/api/` на API кабинета (один источник, CORS не нужен)
- Без внешних шрифтов, CDN, аналитики и счётчиков

## Локальный запуск с подставным API

```sh
npm ci
npm run stub-api   # отдельный терминал: http://127.0.0.1:8091
npm run dev        # кабинет: http://127.0.0.1:5177
```

Тестовые данные (только вымышленные):

| Поле | Значение |
|---|---|
| Телефон | `+7 900 000-00-00` |
| Код | `123456` или длинный пилотный `PilotCode2026Demo` |
| Выбор профиля | телефон `+7 900 000-00-01` → два профиля |

```sh
npm run lint
npm run typecheck
npm test
npm run build
npx playwright test   # локально использует установленный Google Chrome
```

Сборка Docker-образа проверяется в CI (локально Docker не обязателен).

## Переменные

| Где | Имя | Назначение |
|---|---|---|
| Сборка (опционально) | `VITE_CLINIC_PHONE` | запасной телефон на пустом списке записей |
| Контейнер | `API_UPSTREAM` | адрес patient-api, например `http://api-gateway:8080` |
| Контейнер | `CLINIC_PHONE` | телефон клиники; пишется в `/runtime-config.json` при старте |

Секреты и реальные телефоны в репозиторий не коммитятся (см. `.env.example`).
