# medkvadrat-patient-web

Личный кабинет пациента сети клиник МедКвадрат — веб-приложение **только на чтение**.

Пациент входит по телефону и коду, смотрит предстоящие записи, историю посещений и свой профиль. Запись, отмена и перенос приёма в этот репозиторий не входят.

**Статус:** пилот внутри сети клиники.

## Стек

Vite + React + TypeScript, статическая сборка, nginx (непривилегированный) отдаёт статику и проксирует `/api/` на API кабинета.

## Локальный запуск с подставным API

```sh
npm ci
npm run stub-api   # отдельный терминал: подставной API на :8091
npm run dev        # кабинет на :5177, /api проксируется на stub
```

Откройте `http://127.0.0.1:5177`. Тестовый телефон: `+7 900 000-00-00`, код: `123456` (или длинный пилотный `PilotCode2026Demo`).

```sh
npm run lint
npm run typecheck
npm test
npx playwright test
```

Сборка образа проверяется в CI (Docker на машине разработчика не обязателен).
